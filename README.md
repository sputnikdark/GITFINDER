# GITFINDER

Interactive web application for searching and inspecting GitHub user profiles and public repositories using the official GitHub REST API.

## Highlights
- **Object-Oriented Architecture:** Core application logic encapsulated in a clean ES6 `GithubSearch` class.
- **Asynchronous Data Fetching:** Utilizes native `fetch()` with `async/await` to consume the GitHub REST API.
- **Dynamic DOM Rendering:** Instant client-side UI updates displaying user bios, followers, location, and repository lists.
- **Error Handling:** Gracefully handles invalid usernames, HTTP 404 responses, and network edge cases.

## Tech Stack
- JavaScript (ES6+ Classes, Async/Await)
- HTML5
- CSS3 (Flexbox, Responsive Design)
- Official GitHub REST API (v3)

## Getting Started
Clone this repository and open `index.html` in your browser:
```bash
git clone https://github.com/sputnikdark/GITFINDER.git
cd GITFINDER
```
